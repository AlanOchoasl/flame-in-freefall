# Smoke checklist (manual)

Run it on the public URL (https://alanochoasl.github.io/flame-in-freefall/, GitHub Pages) after each deploy and before submission. Open each screen directly by its address. Mark any failure in "Known gaps".

- [ ] **Console** (`#/ranking`, `#/compare`, `#/map` open the same page and scroll to their section; moving between them keeps the page state): four tiles that equal the data (investigations, test records, "N of M investigations have test data", tests in the expected zone); the menu marks the section being read while scrolling (Compare over the comparison, Coverage map over the map, Ranking at the top); the Light/Dark choice survives a reload; below 1024 px the ranking comes before the map; - [ ] **360 px:** no horizontal page scroll on any screen (tables scroll inside their own area); the Menu button opens the navigation; Escape closes it.
- [ ] **No outside requests:** all requests go to the app's own origin; no "MOCKUP" or "sample-placeholder" in the build.
- [ ] **Address state** (`explorer-state`): select the Fire detection profile, add two investigations to the comparison, reload: the profile and the comparison are back; the address reads `#/...?profile=detection&ids=...`. - [ ] **Icon-only controls:** the theme switch (sun, moon), the phone menu (hamburger, close), and on each ranking row Detail, Show tests on the map, Add to the comparison and the PSI link show only an icon with an accessible name and a tooltip that appears at once on hover and on keyboard focus (and on tap) and stays inside the screen (it opens leftward at the right edge and downward in the header); "Interpret" keeps its text; links that open another site (PSI, DOI) end with a small arrow; every icon-only target is 44 px; on a phone the row actions may wrap to two lines but the page does not scroll sideways.
