# Submission check

First re-verify the rules against the official 2026 guide and Terms & Conditions (spaceappschallenge.org); `docs/PLAYBOOK.md` is based on 2025 and may be outdated.

**Demo** (public external link, English or Spanish with English subtitles)
- [ ] Video ≤ 30 s **or** ≤ 7 slides incl. cover. Verify exact length/count.
- [ ] Shows the problem, the solution working, the NASA data used, the impact.
- [ ] Link opens in an incognito window.

**Project page (English)**: title, high-level summary, demo link, repo/prototype link, detailed description, NASA/partner data with links, references, AI-use declaration if applicable.

**Repo**: public, English README (problem, solution, data, run instructions, team), license, no secrets.

**Terms & Conditions 2026** (https://www.spaceappschallenge.org/legal/)
- [ ] LICENSE file in the repo (OSI license; if none, NASA applies Apache 2.0).
- [ ] `node scripts/check-licenses.mjs --write` passes and `THIRD_PARTY_LICENSES.md` is committed; fonts/images/CDN assets checked by hand.
- [ ] Every source cited in the references field, including PSI investigations with DOI.
- [ ] Video is original work; no minors' names/voices/likeness; written consent from any adult shown.
- [ ] AI use described on the project page; AI-generated text labeled in the app.
- [ ] No personal data, no commercial promotion.

**Submit**: T&C checkbox ticked, "Submit" pressed and confirmed **before Sunday 23:00**. Nothing is editable after the deadline.

Video script (30 s): 0–3 team + challenge · 3–10 problem · 10–25 solution + data · 25–30 impact.
Slides (7 max): cover · problem · solution · data used · demo/screens · impact · next steps.
